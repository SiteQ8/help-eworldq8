Worth looking atيستحقّ الفحص

The message on the screen is the clue. Here is how to capture it and what the common ones mean.

الرسالة على الشاشة هي الدليل، وهكذا تلتقطها وهذا ما تعنيه الرسائل الشائعة.

What to do

ما ينبغي فعله

  1. Next time it happens, photograph the screen with your phone before it restarts. The line that says Stop code or the text in capitals is what matters.
  2. Think about what changed. A new program, a Windows update, a new printer or webcam, or new memory installed. Crashes that start right after a change are almost always that change.
  3. If it mentions MEMORY, PAGE FAULT or IRQL, that points at the memory or a driver. If it mentions a file ending in .sys, that is a driver, usually for graphics, network or storage.
  4. Run the built in memory check. On Windows search for Windows Memory Diagnostic and let it restart and test. It takes a while and tells you plainly if the memory is bad.
  5. If it also runs hot or makes noise, the crashes may be heat or a failing drive rather than software. Those two guides cover it.
  1. في المرة القادمة صوّر الشاشة بهاتفك قبل أن يعيد التشغيل، فالسطر الذي يقول Stop code أو النصّ بالحروف الكبيرة هو ما يهمّ.
  2. فكّر فيما تغيّر، برنامج جديد أو تحديث ويندوز أو طابعة أو كاميرا جديدة أو ذاكرة رُكّبت حديثاً، فالأعطال التي تبدأ بعد تغيير تكون ذلك التغيير في الغالب.
  3. فإن ذكرت الرسالة MEMORY أو PAGE FAULT أو IRQL فذلك يشير إلى الذاكرة أو إلى مشغّل، وإن ذكرت ملفاً ينتهي بـ .sys فذلك مشغّل، وغالباً للرسومات أو الشبكة أو التخزين.
  4. شغّل فحص الذاكرة المدمج، ففي ويندوز ابحث عن Windows Memory Diagnostic ودعه يعيد التشغيل ويفحص، ويستغرق وقتاً لكنه يخبرك بوضوح إن كانت الذاكرة معطوبة.
  5. وإن كان يسخن أيضاً أو يصدر صوتاً فقد تكون الأعطال من الحرارة أو من قرص يتعطّل لا من البرمجيات، وذلك ما يغطّيه الدليلان الآخران.

When to stop and ask

متى تتوقّف وتسأل

If it crashes before Windows even finishes loading, or the same crash comes back after the memory test passes, send us the photo of the screen. That message usually tells us exactly what to replace.

فإن كان يتعطّل قبل أن يكتمل تحميل ويندوز، أو عاد العطل نفسه بعد أن نجح فحص الذاكرة، فأرسل لنا صورة الشاشة، فتلك الرسالة تخبرنا غالباً بما ينبغي تبديله بالضبط.
